# ASAL GitHub Pages Site

Generated from Google Takeout Blogger JSON using ASAL converter.

## Deploy

1. Create new repo on GitHub (e.g. `username.github.io` or `blog`)
2. Push these files to `main` branch
3. In repo Settings → Pages → Source: Deploy from branch, Branch: main, Folder: /(root)
4. Your site will be live at `https://username.github.io/` or `https://username.github.io/blog/`

## Structure

- `index.html` - homepage that loads `posts.json`
- `posts.json` - master list
- `posts/*.html` - individual posts
- `assets/css/style.css` - ASAL green theme
- `assets/js/main.js` - nav, progress, back-to-top

Edit `assets/css/style.css` to tweak colors.
